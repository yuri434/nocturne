O código-fonte correspondente e os scripts de compilação acompanham esta distribuição.

A mascote Nocturne é original, gerada para este projeto. Não usa a imagem de banco com marca-d’água.

O setup usa NSIS 3.12; licenças em third_party/NSIS-COPYING.txt. O bootstrapper WebView2 oficial Microsoft está incluído para instalação do componente quando necessário.
